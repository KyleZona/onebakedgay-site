# onebakedgay.com

Source for [onebakedgay.com](https://onebakedgay.com), the home of OneBakedGay: gaming, IT and nerd stuff, live daily on TikTok.

Plain HTML, CSS and JavaScript, hosted free on GitHub Pages. No build step.

## Layout

```
index.html          Home
about.html          About (Windows 98 desktop)
projects.html       Side Projects console + activity log
notes/              Project notes (one HTML file per post)
assets/css/         style.css — shared styles for every page
assets/js/          scripts (schedule countdown, window controls)
assets/img/         logo, photos, icons
.nojekyll           tells GitHub Pages to serve files as-is
```
